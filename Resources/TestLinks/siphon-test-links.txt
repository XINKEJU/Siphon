## ⚠️ FTPS / SMB / NFS / AFP / SCP / rsync — 需要本机服务或 SSH 免密
# FTPS 的公共 rebex 演示站在本机 curl 只返回 150 且无完整数据（err=18），需自建 FTPS 服务
ftps://demo:password@test.rebex.net/readme.txt
# SCP / rsync 引擎使用 `-o BatchMode=yes`，只接受 SSH 密钥免密；URL 里的密码不会被使用，
# 所以 rebex 的 demo/password 不适用于这两条。请改成自己的主机并配好 ~/.ssh 密钥：
#   scp://youruser@yourhost/path/to/file
#   rsync://youruser@yourhost/path/to/file
# SMB / NFS / AFP 需要系统设置里开启「文件共享」，或先手动 mount：
#   smb://youruser@127.0.0.1/Shared/test.txt
#   nfs://your-nas/export/test.txt
#   afp://youruser@yourhost/Shared/test.txt
